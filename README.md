## Структура проекта:
```
istok-backend/
├── alembic/                 # Миграции базы данных (создаст Alembic)
│   └── versions/
├── app/                     # Исходный код приложения
│   ├── api/                 # Роуты (эндпоинты API)
│   ├── core/                # Конфигурация, безопасность, зависимости
│   ├── models/              # SQLAlchemy модели (таблицы БД)
│   ├── schemas/             # Pydantic схемы (валидация запросов/ответов)
│   ├── services/            # Бизнес-логика (поиск дублей, создание событий)
│   └── main.py              # Точка входа (запуск FastAPI)
├── docker-compose.yml       # Конфигурация для запуска БД и Redis
├── Dockerfile               # Инструкции для сборки контейнера приложения
├── .env.example             # Шаблон переменных окружения
├── alembic.ini              # Конфигурация Alembic
└── requirements.txt         # Зависимости Python``
